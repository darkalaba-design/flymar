# FLYMAR

Имиджевая главная FLYMAR на Next.js App Router, TypeScript, Tailwind CSS 4 и Framer Motion. Английская версия — `/`, русская — `/ru`.

## Запуск

Требуется Node.js 22+.

```sh
npm ci
npm run dev
```

Локальный адрес: http://127.0.0.1:3000.

```sh
npm run typecheck
npm run build
npm start
```

Сборка `standalone` подходит для собственного Node.js-хостинга. Можно также подключить GitHub-репозиторий к хостингу с поддержкой Next.js. `npm start` по умолчанию слушает только loopback; для контейнера используйте `next start --hostname 0.0.0.0` или standalone `server.js` с переменными `HOSTNAME` и `PORT`. GitHub Pages без серверной части не поддерживает обработчик заявок.

## Что готово

- Адаптивная главная, оригинальный логотип и оптимизированные WebP из материалов клиента.
- Переключаемый первый экран, анимация появления секций, мобильная навигация.
- Три разных сообщения hero; второй блок Autonomy First с крупными 30 узлами и 70 км по эскизу.
- Слайдер F8 / F9 / F11 / F30 с кнопками, переключателями моделей, свайпом и клавиатурой. У F9/F30 — заглушки изображений.
- Отдельные страницы `/models/f8`, `/models/f11` и их русские версии `/ru/models/f8`, `/ru/models/f11`, характеристики и галереи.
- Нативные модальные окна: F8, интерьер, технологии, форма заявки. Escape, управление клавиатурой, возврат фокуса.
- Уважение системной настройки reduced motion.
- RU/EN, метаданные, изображение для социальных сетей, иконка.
- Серверная проверка полей заявки и готовый адаптер доставки.
- События аналитики без содержимого формы и персональных идентификаторов.

## Заявки

Скопируйте `.env.example` в `.env.local` и задайте `LEADS_ENDPOINT`. Опциональный `LEADS_API_TOKEN` передаётся только с сервера через `Authorization: Bearer …`.

`POST /api/enquiry` проверяет имя, email, длину полей, согласие, язык и honeypot, затем отправляет JSON на настроенный endpoint:

```json
{
  "name": "Example",
  "email": "example@example.com",
  "company": "",
  "message": "",
  "locale": "en",
  "consent": true,
  "source": "flymar-home",
  "submittedAt": "ISO timestamp"
}
```

Ответ endpoint с HTTP 2xx означает успешную доставку. Если endpoint не задан, форма возвращает `503 not_configured`, сохраняет введённые поля в текущем открытом окне и сообщает, что заявка не отправлена. Локальное хранение заявок и фиктивное подтверждение успеха не используются. Перед публичным запуском подключить реальный обработчик, его защиту от массовых отправок и утверждённую компанией политику обработки данных.

## Аналитика

Адаптер: `src/lib/analytics.ts`. Пока `NEXT_PUBLIC_ANALYTICS_ENDPOINT` не указан, внешних запросов нет. Для локальной отладки можно слушать событие браузера `flymar:analytics`.

События: `page_view`, `section_view`, `cta_click`, `modal_open`, `hero_change`, `form_start`, `form_submit`, `form_success`, `form_error`.

Payload: `{ event, properties, path, timestamp }`. Без значений полей, email, query string, cookie и постоянных идентификаторов. При Do Not Track внешняя доставка отключена. Ошибки аналитики не мешают сайту. CORS и конкретный формат endpoint будут согласованы отдельно; сейчас отправляется JSON через `fetch` с `keepalive`.

## Передача и публикация

В репозиторий включить исходники, `public/`, `package.json`, `package-lock.json` и конфигурацию. `START/`, `.work/`, `.env.local`, `node_modules/` и `.next/` исключены. Секреты хранятся в настройках хостинга. `NEXT_PUBLIC_SITE_URL` задаёт основной публичный адрес для метаданных.

Репозиторий проекта: https://github.com/darkalaba-design/flymar. Размещение исходников на GitHub не публикует сайт: для публичного адреса подключите хостинг с поддержкой Next.js.
